Qué es

UN RUNNING TEAM PARA PERSONAS REALES.

  • Para las que recién empiezan.
  • Para las que quieren volver a correr.
  • Para las que necesitan constancia.
  • Y para las que solas siempre encuentran una buena excusa para dejarlo para mañana.

Sprinters Running Team es nuestro espacio de entrenamiento semanal para aprender a correr, progresar y construir el hábito acompañado.

No venís simplemente a sumar kilómetros. Venís a entender cómo correr, mejorar de a poco y descubrir que probablemente podés mucho más de lo que pensabas.

La misma energía de Sprinters. La misma comunidad. Ahora, dos veces por semana.
